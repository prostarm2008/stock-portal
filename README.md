# Prostarm Stock Portal

Static web app (HTML + JavaScript) that keeps its data in SharePoint lists through Power Automate flows.

- Website: GitHub Pages (workflow `.github/workflows/pages.yml`)
- Database: SharePoint lists
- API: Power Automate solution `ProstarmStockPortal` (7 flows)

No user accounts, passwords, hashes, flow URLs or CSV files belong in this repository. The flow URLs live in repository secrets.
